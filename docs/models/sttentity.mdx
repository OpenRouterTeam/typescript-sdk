title: "STTEntity"

A detected entity, returned when the provider runs entity detection

## Example Usage

```typescript
import { STTEntity } from "@openrouter/sdk/models";

let value: STTEntity = {
  endChar: 25,
  startChar: 15,
  text: "John Smith",
  type: "name",
};
```
