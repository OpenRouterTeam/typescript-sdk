What GitHub says the installation covers; null until read.

## Example Usage

```typescript
import { Coverage } from "@openrouter/sdk/models";

let value: Coverage = {
  checkedAt: new Date("2025-09-29T08:31:35.555Z"),
  repositoryCount: 719072,
  selection: "all",
};
```
