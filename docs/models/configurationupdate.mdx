---
title: "ConfigurationUpdate"
---

Mid-conversation configuration update. Changes reasoning effort from this point onward without invalidating the prompt cache for the preceding turns.

## Example Usage

```typescript
import { ConfigurationUpdate } from "@openrouter/sdk/models";

let value: ConfigurationUpdate = {
  reasoning: {
    effort: "low",
  },
};
```
