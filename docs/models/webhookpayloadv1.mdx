---
title: "WebhookPayloadV1"
---

Version 1 recipient-PII-free OpenRouter webhook payload. Under version 1, additive optional fields and new context.kind members are non-breaking; consumers must ignore unknown fields and kinds. Renames, removals, and unit changes require WebhookPayloadV2.

## Example Usage

```typescript
import { WebhookPayloadV1 } from "@openrouter/sdk/models";

let value: WebhookPayloadV1 = {
  alertKey: "<value>",
  calculatedValue: 8078.1,
  dedupKey: "<value>",
  items: [
    {
      context: {
        interval: "lifetime",
        kind: "budget-limit",
        limitUsd: 3029.9,
        spend: 371.34,
        threshold: 4205.32,
        workspaceId: "<id>",
        workspaceName: "<value>",
      },
    },
  ],
  occurredAt: "<value>",
  policyKey: "budget-limit",
  scope: {},
  state: "breach",
  tenantId: "<id>",
  threshold: 1993.78,
  version: 289.33,
};
```
