Token log probability information

## Example Usage

```typescript
import { ChatTokenLogprob } from "@openrouter/sdk/models";

let value: ChatTokenLogprob = {
  bytes: null,
  logprob: -0.612345,
  token: " Hello",
  topLogprobs: [
    {
      bytes: null,
      logprob: -0.612345,
      token: " Hello",
    },
  ],
};
```
