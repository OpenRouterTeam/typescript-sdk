---
title: "PrivateProviderDataPolicy"
---

Defaults to training on and retaining prompts, the most conservative declaration. Your own declaration; it applies to your own traffic and OpenRouter does not verify it.

## Example Usage

```typescript
import { PrivateProviderDataPolicy } from "@openrouter/sdk/models";

let value: PrivateProviderDataPolicy = {
  promptRetentionDays: null,
  retainsPrompts: false,
  training: false,
};
```

## Fields

| Field                                                                       | Type                                                                        | Required                                                                    | Description                                                                 |
| --------------------------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `promptRetentionDays`                                                       | *number*                                                                    | ✔️                                                          | Days prompts are retained. Must be `null` unless `retains_prompts` is true. |
| `retainsPrompts`                                                            | *boolean*                                                                   | ✔️                                                          | Whether the provider retains prompts or completions.                        |
| `training`                                                                  | *boolean*                                                                   | ✔️                                                          | Whether the provider trains on prompts.                                     |
