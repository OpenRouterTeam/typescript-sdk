---
title: "SpeechInputModality"
---

An input the model accepts. `audio` and `image` are `input_references` for voice cloning and voice design.


## Supported Types

### `models.SpeechInputModalityText`

```typescript
const value: models.SpeechInputModalityText = {
  type: "text",
};
```

const value: models.SpeechInputModalityAudio = {

  },

};
