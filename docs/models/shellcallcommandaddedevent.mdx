---
title: "ShellCallCommandAddedEvent"
---

Emitted when a shell command starts streaming into a `shell_call` item's `action.commands`. Carries the command text already received; the remainder follows as `response.shell_call_command.delta` events.

## Example Usage

```typescript
import { ShellCallCommandAddedEvent } from "@openrouter/sdk/models";

let value: ShellCallCommandAddedEvent = {
  command: "<value>",
  commandIndex: 230589,
  outputIndex: 868519,
  sequenceNumber: 0,
  type: "response.shell_call_command.added",
};
```
