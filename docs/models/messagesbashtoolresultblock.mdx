title: "MessagesBashToolResultBlock"

Output of a sandbox-executed `openrouter:bash` call from a prior assistant turn. Accepted on replay and dropped before the provider request — Anthropic has no equivalent block.

## Example Usage

```typescript
import { MessagesBashToolResultBlock } from "@openrouter/sdk/models";

let value: MessagesBashToolResultBlock = {
  content: {
    "command": "ls",
    "exitCode": 0,
    "stderr": "",
    "stdout": "README.md\n",
  },
  toolUseId: "srvtoolu_01abc",
  type: "openrouter_bash_tool_result",
};
```
