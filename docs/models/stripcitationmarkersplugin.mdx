---
title: "StripCitationMarkersPlugin"
---

Removes leaked ChatGPT-internal citation markers (private-use Unicode characters U+E200-U+E20F, e.g. `\ue200cite\ue202turn0search1\ue201`) from assistant text output. Some OpenAI models emit these markers when citing tool results; they only render in ChatGPT's own UI. Opt-in: structured citation annotations are unaffected, but annotation text offsets are not adjusted for removed characters, and logprobs are not rewritten, so removed marker tokens can still appear in logprobs output.

## Example Usage

```typescript
import { StripCitationMarkersPlugin } from "@openrouter/sdk/models";

let value: StripCitationMarkersPlugin = {
  id: "strip-citation-markers",
};
```
