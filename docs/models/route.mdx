The daemon request the proof is for. When present the response also carries the single-use, route-bound proof (`x-ori-invoke-signature-v2`, `x-ori-invoke-nonce`).

## Example Usage

```typescript
import { Route } from "@openrouter/sdk/models";

let value: Route = {
  method: "POST",
  path: "/api/invoke",
};
```
