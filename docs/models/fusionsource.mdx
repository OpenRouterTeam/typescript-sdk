---
title: "FusionSource"
---

A web page retrieved via web search during a fusion run.

## Example Usage

```typescript
import { FusionSource } from "@openrouter/sdk/models";

let value: FusionSource = {
  url: "https://example.com/article",
  title: "Example article title",
};
```

## Fields

| Field                                                                | Type                                                                 | Required                                                             | Description                                                          |
| -------------------------------------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------- |
| `url`                                                                | *string*                                                             | ✔️                                                   | URL of the web page a panel or the analyst retrieved during the run. |
| `title`                                                              | *string*                                                             | ✔️                                                   | Title of the retrieved web page.                                     |
