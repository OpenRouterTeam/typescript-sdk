title: "CompactResponse"

The compacted conversation: pass `output` as the `input` of your next `/responses` request to continue the conversation with the compacted context.

## Example Usage

```typescript
import { CompactResponse } from "@openrouter/sdk/models";

let value: CompactResponse = {
  createdAt: 1700000000,
  id: "resp_abc123",
  object: "response.compaction",
  output: [
    {
      type: "message",
    },
    {
      type: "compaction",
    },
  ],
  usage: {
    inputTokens: 159,
    inputTokensDetails: {
      cachedTokens: 0,
    },
    outputTokens: 928,
    outputTokensDetails: {
      reasoningTokens: 512,
    },
    totalTokens: 1087,
  },
};
```
