---
title: "VisionPlugin"
---

Lets text-only models accept image inputs: images are replaced with deterministic placeholders and the model examines them on demand through the hidden `openrouter:inspect_image` server tool, which dispatches each question to a vision-capable model. Enabled per-request via `plugins` or the `:vision` model variant.

## Example Usage

```typescript
import { VisionPlugin } from "@openrouter/sdk/models";

let value: VisionPlugin = {
  id: "vision",
};
```
