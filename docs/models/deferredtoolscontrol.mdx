---
title: "DeferredToolsControl"
---

Opt-in versioned router-level deferred-tool protocol. Replay assistant reasoning unchanged on continuation; keep the catalog unchanged.

## Example Usage

```typescript
import { DeferredToolsControl } from "@openrouter/sdk/models";

let value: DeferredToolsControl = {
  profile: "portable",
  protocol: "v1",
  search: {
    type: "bm25",
  },
  validation: "runtime",
};
```
