Captured stdout and stderr for one command of a shell call, with its exit or timeout outcome.

## Example Usage

```typescript
import { ShellCallOutputContent } from "@openrouter/sdk/models";

let value: ShellCallOutputContent = {
  outcome: {
    exitCode: 0,
    type: "exit",
  },
  stderr: "",
  stdout: "total 0\n",
};
```
