---
title: "ContainerReferenceEnvironment"
---

Reference to a container by its canonical id — a previously returned container_id or a fresh name to create a persistent container.

## Example Usage

```typescript
import { ContainerReferenceEnvironment } from "@openrouter/sdk/models";

let value: ContainerReferenceEnvironment = {
  containerId: "sess_abc123",
  type: "container_reference",
};
```
