A compound filter that combines multiple comparison or compound filters

## Example Usage

```typescript
import { CompoundFilter } from "@openrouter/sdk/models";

let value: CompoundFilter = {
  type: "and",
  filters: [
    {
      "type": "eq",
      "key": "author",
      "value": "Alice",
    },
  ],
};
```
