---
title: "ToolChoiceSupport"
---

Per-variant `tool_choice` support. `tool_choice` in `supported_parameters` only says the parameter is accepted; these flags say which of its values passed testing.

## Example Usage

```typescript
import { ToolChoiceSupport } from "@openrouter/sdk/models";

let value: ToolChoiceSupport = {
  required: true,
  auto: true,
  function: true,
  none: true,
};
```

## Fields

| Field                                                                                        | Type                                                                                         | Required                                                                                     | Description                                                                                  |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `required`                                                                                   | *boolean*                                                                                    | ✔️                                                                           | Whether the endpoint supports `"tool_choice": "required"`.                                   |
| `auto`                                                                                       | *boolean*                                                                                    | ✔️                                                                           | Whether the endpoint supports `"tool_choice": "auto"`.                                       |
| `function`                                                                                   | *boolean*                                                                                    | ✔️                                                                           | Whether the endpoint supports naming a function, `"tool_choice": {"type": "function", ...}`. |
