---
title: "SignInternDaemonResponse"
---

Headers the CLI copies onto the daemon request so the sidecar can verify who is asking.

## Example Usage

```typescript
import { SignInternDaemonResponse } from "@openrouter/sdk/models";

let value: SignInternDaemonResponse = {
  xOriInvokeSignature: "MEUCIQ...",
  xOriInvokeTimestamp: "1789000000",
  xOriInvokeUser: "user_2abc",
};
```
