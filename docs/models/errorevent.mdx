Event emitted when an error occurs during streaming

## Example Usage

```typescript
import { ErrorEvent } from "@openrouter/sdk/models";

let value: ErrorEvent = {
  type: "error",
  code: "<value>",
  message: "<value>",
  param: "<value>",
  sequenceNumber: 0,
};
```
