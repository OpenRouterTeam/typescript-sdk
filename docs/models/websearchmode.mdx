---
title: "WebSearchMode"
---

Engine-native search mode; the accepted values depend on the selected engine. Parallel: turbo, basic (default), or advanced. Rejected when the selected engine doesn't offer the given mode.

## Example Usage

```typescript
import { WebSearchMode } from "@openrouter/sdk/models";

let value: WebSearchMode = "basic";

// Open enum: unrecognized values are captured as Unrecognized<string>
```

## Values

```typescript
"turbo" | "basic" | "advanced" | Unrecognized<string>
```
