---
title: "BatchProviderPreferences"
---

Batch provider routing preferences. Only `provider.only` and `provider.allow_fallbacks` are supported.

## Example Usage

```typescript
import { BatchProviderPreferences } from "@openrouter/sdk/models";

let value: BatchProviderPreferences = {};
```
