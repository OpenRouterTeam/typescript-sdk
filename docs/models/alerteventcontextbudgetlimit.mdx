PII-free context for a budget-limit alert event.

## Example Usage

```typescript
import { AlertEventContextBudgetLimit } from "@openrouter/sdk/models";

let value: AlertEventContextBudgetLimit = {
  interval: "monthly",
  kind: "budget-limit",
  limitUsd: 1399.55,
  spend: 9111.82,
  threshold: 9527.28,
  workspaceId: "<id>",
  workspaceName: "<value>",
};
```
