title: "ToolSearchServerTool"
---

OpenRouter built-in server tool: finds tools marked `defer_loading` and makes them callable, by natural-language query (`bm25`, the default) or by regular expression (`regex`)

## Example Usage

```typescript
import { ToolSearchServerTool } from "@openrouter/sdk/models";

let value: ToolSearchServerTool = {
  type: "openrouter:tool_search",
};
```
