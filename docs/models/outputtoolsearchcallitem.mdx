---
title: "OutputToolSearchCallItem"
---

A call the model made to a `tool_search` tool declared with `"execution": "client"`. The client runs the search and replays this item with a `tool_search_output` item.

## Example Usage

```typescript
import { OutputToolSearchCallItem } from "@openrouter/sdk/models";

let value: OutputToolSearchCallItem = {
  callId: "<id>",
  execution: "client",
  status: "completed",
  type: "tool_search_call",
};
```
