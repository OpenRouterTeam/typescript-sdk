title: "DeferredBm25Search"

Deterministic BM25 retrieval over supplied tool definitions.

## Example Usage

```typescript
import { DeferredBm25Search } from "@openrouter/sdk/models";

let value: DeferredBm25Search = {
  type: "bm25",
};
```

                                                                                   | Universal profile only, for searches the router answers through the `tool_search` wrapper. When true, a search that matches nothing also names the deferred sources this search covers (namespaces, MCP servers, and shared `<server>_` prefixes; up to 40 names or 2,000 characters, with a count of any omitted) and tells the model that a source the search does not cover is unreachable through it in this request, so it can make a client tool call the task already needs (or a read-only one) and search again on a later turn instead of concluding the integration is missing. A hit gets the same guidance after its matches when, as a heuristic on the model's own words, the query's leading word has 3 to 64 characters, no query word names a searchable source, and no deferred tool's name or indexed description (its own and its namespace's) carries the leading word (`jira create issue` answered with another tracker's issue tools). Direct tools, including a client's built-in tools, are already in the tool list and are not named. Absent or false: a miss suggests other keywords and the closest names only. |
