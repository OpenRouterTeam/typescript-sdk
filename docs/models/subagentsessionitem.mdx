title: "SubagentSessionItem"

One item of a subagent's session transcript (a Responses conversation item: message, function call, reasoning, ...). Replay it unmodified so the subagent can be reconstructed statelessly.

## Example Usage

```typescript
import { SubagentSessionItem } from "@openrouter/sdk/models";

let value: SubagentSessionItem = {
  type: "<value>",
};
```
