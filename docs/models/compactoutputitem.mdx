title: "CompactOutputItem"

An item in the compacted context window — echoed input items followed by a single `compaction` item carrying the encrypted summary of the compacted history.

## Example Usage

```typescript
import { CompactOutputItem } from "@openrouter/sdk/models";

let value: CompactOutputItem = {
  type: "compaction",
};
```
