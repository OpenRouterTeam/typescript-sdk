title: "PrivateEndpointPromptCaching"
---

Prompt-caching controls for an OpenAI-compatible private endpoint. Accepted fields default on after validation; explicit owner settings override the defaults.

## Example Usage

```typescript
import { PrivateEndpointPromptCaching } from "@openrouter/sdk/models";

let value: PrivateEndpointPromptCaching = {
  cacheControl: false,
  promptCacheKey: false,
};
```
