Beta. The result of the alignment plugin for this request; the shape may change.

## Example Usage

```typescript
import { Alignment } from "@openrouter/sdk/models";

let value: Alignment = {
  calls: [
    {
      call: 1,
      outcome: "allowed",
      rules: [
        {
          broken: false,
          probability: 0.04,
        },
      ],
    },
  ],
};
```
