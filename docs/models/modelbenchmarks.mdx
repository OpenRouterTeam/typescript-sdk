---
title: "ModelBenchmarks"
---

Third-party benchmark rankings for this model. Omitted when no benchmark data is available.

## Example Usage

```typescript
import { ModelBenchmarks } from "@openrouter/sdk/models";

let value: ModelBenchmarks = {
  designArena: [
    {
      arena: "models",
      category: "website",
      elo: 1385.2,
      rank: 5,
      winRate: 62.5,
    },
  ],
};
```
