A function call initiated by the model

## Example Usage

```typescript
import { FunctionCallItem } from "@openrouter/sdk/models";

let value: FunctionCallItem = {
  arguments: "{\"location\":\"San Francisco\"}",
  callId: "call-abc123",
  id: "call-abc123",
  name: "get_weather",
  type: "function_call",
};
```
