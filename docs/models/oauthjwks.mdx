RFC 7517 JWK Set of the keys OpenRouter signs access tokens with.

## Example Usage

```typescript
import { OAuthJwks } from "@openrouter/sdk/models";

let value: OAuthJwks = {
  keys: [
    {
      alg: "ES256",
      crv: "P-256",
      kid: "or-2026-09",
      kty: "EC",
      use: "sig",
      x: "f83OJ3D2xF1Bg8vub9tLe1gHMzV76e8Tus9uPHvRVEU",
      y: "x_FEzRu9m36HLN_tue659LNpXW6pCyStikYjKIWI5a0",
    },
  ],
};
```
