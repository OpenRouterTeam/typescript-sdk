---
title: "WebSearchServerToolConfigMode"
---

Engine-specific search mode. Currently supported for the Parallel engine: turbo (~200 ms, $1/1k requests, English and Japanese), basic (~1 s, $5/1k, default), or advanced (~3 s, $5/1k). Rejected when the selected engine doesn't offer the given mode.

## Example Usage

```typescript
import { WebSearchServerToolConfigMode } from "@openrouter/sdk/models";

let value: WebSearchServerToolConfigMode = "basic";

// Open enum: unrecognized values are captured as Unrecognized<string>
```

## Values

```typescript
"turbo" | "basic" | "advanced" | Unrecognized<string>
```
