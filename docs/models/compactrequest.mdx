---
title: "CompactRequest"
---

Request body for compacting a conversation into a smaller context window. Only supported on OpenAI and Azure endpoints.

## Example Usage

```typescript
import { CompactRequest } from "@openrouter/sdk/models";

let value: CompactRequest = {
  model: "openai/gpt-5.2",
};
```
