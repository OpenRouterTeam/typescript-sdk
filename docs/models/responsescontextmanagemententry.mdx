---
title: "ResponsesContextManagementEntry"
---

A context management entry. Currently only `type: 'compaction'` is supported, which lets the provider automatically compact the conversation into an encrypted compaction item when the context window fills up (optionally at `compact_threshold` input tokens).

## Example Usage

```typescript
import { ResponsesContextManagementEntry } from "@openrouter/sdk/models";

let value: ResponsesContextManagementEntry = {
  type: "compaction",
};
```
