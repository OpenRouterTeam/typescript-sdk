Tool search result from a prior assistant turn, returned beside the `server_tool_use` it answers.

## Example Usage

```typescript
import { MessagesToolSearchToolResultBlock } from "@openrouter/sdk/models";

let value: MessagesToolSearchToolResultBlock = {
  content: {
    toolReferences: [
      {
        toolName: "get_weather",
        type: "tool_reference",
      },
    ],
    type: "tool_search_tool_search_result",
  },
  toolUseId: "srvtoolu_01abc",
  type: "tool_search_tool_result",
};
```
