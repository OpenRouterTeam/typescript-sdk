title: "FusionServerToolConfigAnalysisMode"

Selects how the judge stage synthesizes panel responses. `generic` uses the five research dimensions tuned for one-off UI fusion. `coding` swaps in action-oriented dimensions for multi-turn coding. `council` skips the judge call entirely and returns the raw panel responses. When omitted, the default depends on the entry path: a `coding-*` preset implies `council`, the server-tool (agent) path defaults to `coding`, and the `openrouter/fusion` model-slug path defaults to `generic`.

## Example Usage

```typescript
import { FusionServerToolConfigAnalysisMode } from "@openrouter/sdk/models";

let value: FusionServerToolConfigAnalysisMode = "coding";

// Open enum: unrecognized values are captured as Unrecognized<string>
```
