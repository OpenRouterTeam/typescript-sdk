---
title: "BatchInputReference"
---

A batch input file in your own storage, named in place of `requests`. Available to allowlisted callers on Google Vertex BYOK endpoints only.

## Example Usage

```typescript
import { BatchInputReference } from "@openrouter/sdk/models";

let value: BatchInputReference = {
  uri: "gs://my-bucket/batches/input.jsonl",
};
```
