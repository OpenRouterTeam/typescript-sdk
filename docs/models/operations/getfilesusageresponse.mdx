Storage usage for the entity, broken down by workspace.

## Example Usage

```typescript
import { GetFilesUsageResponse } from "@openrouter/sdk/models/operations";

let value: GetFilesUsageResponse = {
  limitBytes: 10737418240,
  usedBytes: 1048576,
  workspaces: [
    {
      fileBytes: 1024000,
      sessionBytes: 24576,
      workspaceId: "11111111-1111-4111-8111-111111111111",
    },
  ],
};
```
