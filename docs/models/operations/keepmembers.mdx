---
title: "KeepMembers"
---

Whether to keep workspace members after deleting the mapping. Defaults to `false`, which **removes** the members this mapping granted access to. Pass `true` to delete the mapping while leaving membership intact. Note this differs from the dashboard, which always sends an explicit choice rather than relying on the default.


## Supported Types

### `operations.KeepMembersEnum`

```typescript
const value: operations.KeepMembersEnum = "false";
```

### `boolean`

```typescript
const value: boolean = false;
```
