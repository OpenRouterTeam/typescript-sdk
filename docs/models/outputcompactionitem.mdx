---
title: "OutputCompactionItem"
---

A compaction item produced by server-side context compaction (`context_management`). The `encrypted_content` blob is only decryptable by the provider endpoint that produced it — echo the item back verbatim on subsequent requests and OpenRouter will route the conversation to that endpoint.

## Example Usage

```typescript
import { OutputCompactionItem } from "@openrouter/sdk/models";

let value: OutputCompactionItem = {
  encryptedContent: "<value>",
  id: "msg-abc123",
  type: "compaction",
};
```
