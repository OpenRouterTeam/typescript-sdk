---
title: "KeyBudget"
---

One budget layer that applies to requests made with this key, with the spend enforcement compares against it.

## Example Usage

```typescript
import { KeyBudget } from "@openrouter/sdk/models";

let value: KeyBudget = {
  budgetId: null,
  guardrailId: "0df9e665-d932-5740-b2c7-b52af166bc11",
  includeByok: false,
  limitUsd: 50,
  remainingUsd: 17.5,
  resetInterval: "weekly",
  resetsAt: new Date("2026-10-12T00:00:00.000Z"),
  scope: "member",
  spendUsd: 32.5,
};
```
