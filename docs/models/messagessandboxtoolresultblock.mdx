title: "MessagesSandboxToolResultBlock"

Output of an `openrouter:sandbox` file operation from a prior assistant turn. Accepted on replay and dropped before the provider request — Anthropic has no equivalent block.

## Example Usage

```typescript
import { MessagesSandboxToolResultBlock } from "@openrouter/sdk/models";

let value: MessagesSandboxToolResultBlock = {
  content: {
    "operation": "read",
    "output": "export const answer = 42;\n",
    "path": "src/index.ts",
  },
  toolUseId: "srvtoolu_01abc",
  type: "openrouter_sandbox_tool_result",
};
```
