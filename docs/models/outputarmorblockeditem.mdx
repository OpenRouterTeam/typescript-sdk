---
title: "OutputArmorBlockedItem"
---

A client tool call that OpenRouter Armor blocked. Emitted in place of the call when `plugins[armor].output_mode` is `custom_item`.

## Example Usage

```typescript
import { OutputArmorBlockedItem } from "@openrouter/sdk/models";

let value: OutputArmorBlockedItem = {
  arguments: "<value>",
  callId: "<id>",
  explanation: "<value>",
  id: "msg-abc123",
  name: "<value>",
  reason: "<value>",
  status: "completed",
  type: "openrouter:armor_blocked",
};
```
