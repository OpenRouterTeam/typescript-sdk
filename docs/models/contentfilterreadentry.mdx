A custom regex content filter, with whether inference enforces it.

## Example Usage

```typescript
import { ContentFilterReadEntry } from "@openrouter/sdk/models";

let value: ContentFilterReadEntry = {
  action: "redact",
  pattern: "\\b(sk-[a-zA-Z0-9]{48})\\b",
  isEnforced: true,
};
```
