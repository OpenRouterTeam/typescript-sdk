---
title: "PrivateEndpointSettings"
---

Capabilities and limits routing uses for this endpoint. A new endpoint copies them from the public endpoint for the same model and provider, or from the model, and the owner can change them. Rate limits are not part of this object: a private endpoint is billed to its own upstream key, so request limits stay with the provider.

## Example Usage

```typescript
import { PrivateEndpointSettings } from "@openrouter/sdk/models";

let value: PrivateEndpointSettings = {
  completions: {
    chat: true,
    text: false,
  },
  contextLength: 128000,
  excludedParameters: [
    "logit_bias",
  ],
  inputs: {
    audio: false,
    base64Files: null,
    base64Images: true,
    fileUrls: null,
    imageUrls: true,
  },
  maxCompletionTokens: 16384,
  maxPromptTokens: null,
  quantization: "bf16",
  reasoning: {
    returnMechanism: "reasoning",
    supported: true,
  },
  toolChoice: {
    auto: true,
    function: false,
    none: true,
    required: true,
  },
};
```
