---
title: "OutputShellCallOutputItem"
---

A native `shell_call_output` item matching OpenAI's Responses API shape. Carries per-command stdout, stderr, and the exit/timeout outcome. A sandbox failure terminates the item as `incomplete` with `error` set.

## Example Usage

```typescript
import { OutputShellCallOutputItem } from "@openrouter/sdk/models";

let value: OutputShellCallOutputItem = {
  callId: "<id>",
  id: "msg-abc123",
  output: [
    {
      outcome: {
        exitCode: 0,
        type: "exit",
      },
      stderr: "",
      stdout: "total 0\n",
    },
  ],
  status: "completed",
  type: "shell_call_output",
};
```
