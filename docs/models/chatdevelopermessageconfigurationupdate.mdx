title: "ChatDeveloperMessageConfigurationUpdate"
---

OpenRouter extension. Same as the system message `configuration_update`: changes reasoning effort from this point in the conversation onward without invalidating the prompt cache for the preceding turns.

## Example Usage

```typescript
import { ChatDeveloperMessageConfigurationUpdate } from "@openrouter/sdk/models";

let value: ChatDeveloperMessageConfigurationUpdate = {
  reasoning: {
    effort: "low",
  },
};
```
