A user message. When it is the last message its text is the prompt for a new run, at most 32000 characters.

## Example Usage

```typescript
import { InternChatUserMessage } from "@openrouter/sdk/models";

let value: InternChatUserMessage = {
  content: "Summarize the open pull requests.",
  role: "user",
};
```
