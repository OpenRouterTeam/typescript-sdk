---
title: "SpeechModelResponse"
---

A text-to-speech model. Its members are the envelope of its endpoints': enums are unioned and ranges widened, so a value inside a range may be accepted by no single endpoint. Each record in `endpoints` lists exactly what that endpoint accepts.

## Example Usage

```typescript
import { SpeechModelResponse } from "@openrouter/sdk/models";

let value: SpeechModelResponse = {
  created: 1742428800,
  description: "Text-to-speech model with steerable delivery.",
  endpoints: [
    {
      inputModalities: [
        {
          type: "text",
        },
      ],
      outputModalities: [
        {
          supportedParameters: {},
          type: "speech",
        },
      ],
      providerName: "OpenAI",
      providerSlug: "openai",
    },
  ],
  id: "openai/gpt-4o-mini-tts",
  inputModalities: [
    {
      type: "text",
    },
  ],
  name: "OpenAI: GPT-4o mini TTS",
  outputModalities: [
    {
      supportedParameters: {},
      type: "speech",
    },
  ],
};
```
