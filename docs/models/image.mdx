title: "Image"
---

The image returned by a read of an image file, base64-encoded and already fitted to the model’s input limits.

## Example Usage

```typescript
import { Image } from "@openrouter/sdk/models";

let value: Image = {
  data: "<value>",
  height: 303822,
  mimeType: "<value>",
  originalHeight: 414391,
  originalWidth: 236903,
  width: 901803,
};
```
