## Example Usage

```typescript
import { VideoGenerationUsage } from "@openrouter/sdk/models";

let value: VideoGenerationUsage = {};
```

| Field                                                                  | Type                                                                   | Required                                                               | Description                                                            |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `cost`                                                                 | *number*                                                               | ➖                                                     | The cost of the video generation in USD.                               |
| `isByok`                                                               | *boolean*                                                              | ➖                                                     | Whether the request was made using a Bring Your Own Key configuration. |
