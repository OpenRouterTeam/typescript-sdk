title: "ArmorSafeguardResult"
---

The outcome of OpenRouter Armor for each client tool call of the response, keyed by tool-call id, in the same shape Anthropic reports its server-side safeguards.

## Example Usage

```typescript
import { ArmorSafeguardResult } from "@openrouter/sdk/models";

let value: ArmorSafeguardResult = {
  type: "dangerous_tool_use",
  status: {
    type: "available",
    toolUses: {
      "call_abc": {
        type: "evaluated",
        outcome: "flagged",
      },
      "call_def": {
        type: "evaluated",
        outcome: "not_flagged",
      },
    },
  },
};
```
