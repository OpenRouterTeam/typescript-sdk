## Overview

### Available Operations

* [create](#create) - Create an organization for a Connect client

## create

Create an organization owned by a managed user and grant it to the calling Connect client. Replaying the same external ID returns the organization created by the first call. The organization is created unfunded: fund it before inference. Organization provisioning key required. A management key cannot call this endpoint.

### Example Usage

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.orgs.create({
    requestBody: {
      email: "Trey.Stark-Hane@yahoo.com",
      externalId: "<id>",
      name: "<value>",
      scopes: [],
    },
  });

  console.log(result);
}

run();
```
