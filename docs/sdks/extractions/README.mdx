## Overview

Alpha feature endpoints for Extractions requests

### Available Operations

* [create](#create) - Submit an Extractions request

## create

Extracts, computes, estimates or forecasts typed fields from a state string and image assets using an extraction-style System One model. Alpha: the shape is not stable.

### Example Usage

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.alpha.extractions.create({
    extractionsRequest: {
      fields: {
        "contacts": {
          items: "text",
          type: "list",
        },
        "days_to_pay": {
          max: 120,
          min: 0,
          step: 1,
          type: "estimate",
        },
        "due_date": {
          instructions: "Issue date plus the net payment days",
          type: "date",
        },
        "invoice_number": {
          type: "text",
        },
        "total": {
          decimals: 2,
          type: "number",
          unit: "USD",
        },
      },
      model: "cloudflare/clairic",
      referenceDate: "2026-10-28",
      state: "Invoice INV-2291 issued 2026-09-02, net 30. Contacts: Dana Ruiz, Priya Shah. Total $1080.",
    },
  });

  console.log(result);
}

run();
```
