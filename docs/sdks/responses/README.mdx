## Overview

### Available Operations

* [send](#send) - Create a response
* [compact](#compact) - Compact a conversation

## send

Creates a streaming or non-streaming response using OpenResponses API format

### Example Usage: guardrail-blocked

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.responses.send({
    responsesRequest: {},
  });

  console.log(result);
}

run();
```

## compact

Rewrites a conversation into a smaller context window, returning the canonical next context window: echoed input items followed by a `compaction` item that encodes the compacted history. Pass the returned `output` as the `input` of your next `/responses` request. Currently supported on OpenAI and Azure endpoints only; OpenRouter routes follow-up requests carrying the compaction item back to the producing endpoint.

### Example Usage: guardrail-blocked

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.responses.compact({
    compactRequest: {
      model: "openai/gpt-5.6-luna",
    },
  });

  console.log(result);
}

run();
```
