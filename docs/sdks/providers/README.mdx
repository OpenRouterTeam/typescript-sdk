## Overview

### Available Operations

* [list](#list) - List all providers
* [listProviderEndpoints](#listproviderendpoints) - List a provider's endpoints with provider-wide stats

## list

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",

});

async function run() {
  const result = await openRouter.providers.list();

  console.log(result);
}

run();
```

## listProviderEndpoints

Returns every endpoint the provider serves, hidden ones included, with the provider-wide uptime, routing, latency and throughput stats over the window. Requires provider ownership, membership, or admin access.

### Example Usage

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.providers.listProviderEndpoints({
    providerSlug: "fireworks",
    window: "1d",
  });

  console.log(result);
}

run();
```
