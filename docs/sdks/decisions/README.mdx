## decisions

Submits a Decisions request to the Decisions router

### Example Usage

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.decisions.decisions({
    decisionsRequest: {
      model: "Grand Cherokee",
      questions: {

      },
      state: "Maine",
    },
  });

  console.log(result);
}

run();
```
