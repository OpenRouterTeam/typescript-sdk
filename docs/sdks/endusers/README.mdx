## Overview

Deprecated alias of externalUsers. Use externalUsers instead; scheduled for removal (sunset date TBD).

### Available Operations

* [list](#list) - List registered external users
* [create](#create) - Register an external user
* [delete](#delete) - Deactivate a registered external user
* [get](#get) - Get a registered external user
* [update](#update) - Update a registered external user

## list

List registrations belonging to the authenticated organization. Inactive registrations are excluded by default. [Management key](/docs/guides/overview/auth/management-api-keys) required.

### Example Usage

```typescript

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.endUsers.list();

  for await (const page of result) {
    console.log(page);
  }
}

run();
```
