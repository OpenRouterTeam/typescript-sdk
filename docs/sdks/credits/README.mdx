## Overview

Credit management endpoints

### Available Operations

* [getCurrentBudget](#getcurrentbudget) - Get budgets for the current API key
* [getCredits](#getcredits) - Get remaining credits

## getCurrentBudget

Returns every spending budget that constrains the API key making the request — account credits, the key limit, guardrail budgets, and workspace budgets — with the limit, reset interval, and spend so far for each. Intended for agents that regulate their own spend. [API key](/docs/api-reference/authentication) required.

### Example Usage

```typescript
import { OpenRouter } from "@openrouter/sdk";

const openRouter = new OpenRouter({
  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
});

async function run() {
  const result = await openRouter.credits.getCurrentBudget({
    bearer: process.env["OPENROUTER_BEARER"] ?? "",
  });

  console.log(result);
}

run();
```

## getCredits

### Example Usage

```typescript

  httpReferer: "<value>",
  appTitle: "<value>",
  appCategories: "<value>",
  apiKey: process.env["OPENROUTER_API_KEY"] ?? "",
});

async function run() {
  const result = await openRouter.credits.getCredits();

  console.log(result);
}
```
